# مصحف ليبيا — رواية قالون عن نافع

تطبيق مصحف تفاعلي (Capacitor + HTML/JS) يعمل على أندرويد.

## المزايا
- نص المصحف كاملاً مضمّن (بدون إنترنت)، وبحث متقدم يتجاهل التشكيل
- 6 تفاسير و8 ترجمات مضمّنة
- نظام حفظ بالتكرار المتباعد (SRS) مع إحصاءات
- علامات وملاحظات على الآيات والسور
- تلاوة بالصوت مع تحميل المصحف الصوتي للاستماع أوفلاين
- لوحة «Aa» للقراءة: حجم الخط وتباعد الأسطر ومظهر (فاتح/ورقي/داكن) ونمط «المصحف المتصل» ووضع التركيز
- شريط الأدوات يختفي عند التمرير لمساحة قراءة أكبر
- تحديث تلقائي (OTA) عبر GitHub Releases

## الحصول على APK
1. تبويب **Actions** ← آخر تشغيل لـ *Build APK + Update Bundle* ← **Artifacts** ← `libya-quran-apk`
2. أو من **Releases** ← الإصدار `latest` ← `libya-quran.apk`

> APK الناتج «debug». عند تثبيت إصدار جديد فوق قديم قد يطلب أندرويد إزالة القديم أولاً لأن مفتاح التوقيع يختلف بين عمليات البناء.

## التطوير محلياً
```bash
npm install
npm start          # معاينة www على http://localhost:3000
npx cap sync android
```

## ملاحظات
- التحديث التلقائي يعمل عند الدمج في `main` (يُنشر `bundle.zip` و`update.json`).
- التلوين التجويدي تقريبي (قواعد نصية) وليس مرجعاً شرعياً.

## خط المصحف
ضع ملف `AmiriQuran-Regular.woff2` (خط Amiri Quran المفتوح المصدر) في `www/fonts/` ليُستخدم تلقائياً؛ وإلا يُستخدم أقرب خط نسخي في الجهاز.
