# مصحف ليبيا — رواية قالون عن نافع

تطبيق مصحف تفاعلي (Capacitor + HTML/JS) يعمل على أندرويد — الإصدار 1.1.0.

## المزايا
- نص المصحف كاملاً مضمّن (بدون إنترنت): مصحف الأوقاف الليبية برواية قالون، العدّ المدني الأخير (6214 آية)، وبحث متقدم يتجاهل التشكيل
- 6 تفاسير كاملة لكل السور الـ114 (الميسّر، ابن كثير، الجلالين، السعدي، الطبري، القرطبي) و8 ترجمات — كلها مضمّنة
- ربط آلي بين عدّ قالون وعدّ حفص: التفاسير والترجمات مرقّمة بحفص، ويطابقها التطبيق مع آيات قالون عبر بيانات الربط في المصحف نفسه، فلا تنزاح آية عن تفسيرها
- نظام حفظ بالتكرار المتباعد (SRS) مع إحصاءات
- علامات وملاحظات على الآيات والسور (تُعرض مُعقّمة ضد أي وسوم)
- تلاوة عبد الباسط عبد الصمد (سورة كاملة) مع تحميل المصحف الصوتي للاستماع أوفلاين
- لوحة «Aa» للقراءة: حجم الخط وتباعد الأسطر ومظهر (فاتح/ورقي/داكن) ونمط «المصحف المتصل» ووضع التركيز
- خط المصحف Amiri Quran مضمّن فعليًا في التطبيق
- شريط الأدوات يختفي عند التمرير لمساحة قراءة أكبر
- تحديث تلقائي (OTA) عبر GitHub Releases

## الحصول على APK
1. تبويب **Actions** ← آخر تشغيل لـ *Build APK + Update Bundle* ← **Artifacts** ← `libya-quran-apk`
2. أو من **Releases** ← الإصدار `latest` ← `libya-quran.apk`

## التوقيع (مهم للتحديثات)
- البناء المحلي ونسخ الإصدار تُوقَّع بمفتاح دائم واحد، فتتثبّت التحديثات فوق القديم دون إزالة.
- لبناء GitHub Actions الموقّع بنفس المفتاح أضف أسرار المستودع (Settings ← Secrets ← Actions):
  `QURAN_KEYSTORE_BASE64` (محتوى ملف الـ keystore بصيغة base64)، `QURAN_KEYSTORE_PASSWORD`، `QURAN_KEY_ALIAS`، `QURAN_KEY_PASSWORD`.
  عند غيابها يبني سير العمل نسخة Debug كاحتياط (توقيعها يتغير كل مرة).

## التطوير محلياً
```bash
npm install
npm run verify     # فحص سلامة البيانات: اكتمال المصحف والتفاسير والترجمات والخط
npm start          # معاينة www على http://localhost:3000
npx cap sync android
```

## ملاحظات
- التحديث التلقائي يعمل عند الدمج في `main` (يُنشر `bundle.zip` و`update.json`).
- التلوين التجويدي تقريبي (قواعد نصية) وليس مرجعاً شرعياً.
- مصادر البيانات وإسنادها (الموسوعة القرآنية Quranpedia.net وغيرها) موثّقة في `NOTICE.md`، ورخصة الكود في `LICENSE`.

## ما تغيّر في 1.1.0
- إكمال التفسيرين الناقصين: الجلالين (كان 103/114 سورة) والقرطبي (كان 100/114) — الآن الستة كاملة
- تصحيح فهرس السور لعدّ قالون المدني (6214) بعد أن كان بعدّ حفص (6236) مخالفًا للنص في 50 سورة
- ربط التفسير والترجمة بعدّ حفص عبر `number_in_hafs` بدل الترقيم المباشر
- دمج ملف الترقيع `app-patches.js` في `app.js` وإلغاء ازدواج منطق التحديثات
- تضمين خط Amiri Quran فعليًا، وتعقيم عرض الملاحظات في كل المسارات
- إزالة الكود الميت (قالب Vite ومكتبة howler غير المستخدمة) وإيقاف `cleartext`/`allowMixedContent`
- فحص بيانات آلي `npm run verify` يعمل في CI قبل البناء، وتوقيع Release دائم
