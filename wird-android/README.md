# وِرد — تطبيق القرآن الكريم دون اتصال

تطبيق Android أصلي باستخدام Kotlin وJetpack Compose. لا يستخدم الذكاء الاصطناعي ولا يحتاج إلى اتصال شبكة أثناء الاستخدام.

## الوظائف في هذا الإصدار
- واجهة عربية RTL بهوية زمردية وذهبية.
- فهرس السور الـ114 والنص القرآني يُضمّن في APK وقت البناء من Tanzil.
- بحث محلي في النص.
- حفظ آخر موضع قراءة والمفضلة محليًا.
- شاشة قراءة نصية قابلة للتكبير.
- إعدادات الثيم وحجم الخط.
- إعداد بناء APK بواسطة GitHub Actions.

## موارد تحتاج إلى ترخيص مستقل قبل إصدار كامل
هذا المستودع لا يضمّن صور صفحات المصحف الأصلية ولا ملفات التلاوة الصوتية؛ يجب إضافة مجموعات مرخصة صراحةً لإعادة التوزيع داخل APK. لا يُعد وجود الملفات على موقع ما إذنًا بإعادة توزيعها. شاشة الصوت تبيّن ذلك بدلًا من ادعاء وجود تسجيلات غير مرفقة.

## مصدر النص
Tanzil Quran Text (Uthmani), https://tanzil.net  
يُضمّن النص كما تم تنزيله دون تغيير، مع الإشارة إلى المصدر وشروطه. لا تعدّل نص القرآن يدويًا.

## البناء
يدعم سير العمل في GitHub Actions بناء APK تجريبي عند دفع التغييرات إلى فرع wird-android-offline. نزّل APK من قسم Artifacts في تشغيل Actions.

## الترخيص
الشيفرة الخاصة بهذا المشروع: MIT. نص القرآن تابع لشروط Tanzil المبينة أعلاه. الصور والتسجيلات عند إضافتها تخضع لتراخيص مستقلة.
