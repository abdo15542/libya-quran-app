# وِرد — تطبيق القرآن الكريم دون اتصال

تطبيق Android أصلي بلغة Kotlin وJetpack Compose، بهوية زمردية وذهبية وواجهة عربية RTL. لا يستخدم الذكاء الاصطناعي، ولا يطلب إذن الإنترنت في التطبيق المثبت.

## ما يحتويه المشروع حاليًا
- فهرس السور الـ114 والنص العثماني من Tanzil مضمّن في APK عند البناء.
- بحث محلي في الآيات، مع تطبيع أحرف البحث فقط لتجاوز اختلاف الحركات وبعض أشكال الألف والياء. النص المعروض لا يُعدّل.
- قراءة نصية، تكبير الخط، الوضع الليلي، وحفظ آخر سورة والمفضلة محليًا.
- عارض صفحات لمصحف المدينة النبوية برواية حفص، 604 صفحة SVG تُنزّل وقت البناء من مصدر مثبت الإصدار ثم تُضمّن داخل APK.
- اختبارات آلية تتحقق من وجود 114 سورة و6236 آية وتطابق عدد الآيات لكل سورة، وكذلك وجود صفحات المصحف الـ604.
- GitHub Actions لبناء APK تجريبي ورفعه ضمن Artifacts.

## التلاوة الصوتية — غير مكتملة بعد
لم تُضمّن ملفات صوتية في هذه النسخة، ولذلك لا يمكن تشغيل التلاوة حتى الآن. يجب إضافة تسجيل كامل لقارئ واحد من مصدر يسمح صراحةً بإعادة التوزيع داخل التطبيق، ثم إضافة مشغل محلي واختبار تشغيله دون اتصال. لا يتم بث أي صوت عبر الإنترنت.

## بناء APK
من المستودع، افتح تبويب Actions وشغّل workflow المسمى **Build Wird Android APK**، أو ادفع تحديثًا إلى الفرع `wird-android-offline`. يبني workflow النص والصفحات المرخصة ثم يتحقق منها قبل تجميع APK. نزّل `Wird-debug-APK` من Artifacts.

يتطلب البناء اتصالًا بالإنترنت لتنزيل المصادر الرسمية. بعد تثبيت APK، النص وصفحات المصحف محلية بالكامل ولا يحتاج عرضها إلى الإنترنت.

## مصادر البيانات والتراخيص
- نص القرآن العثماني: [Tanzil](https://tanzil.net/docs/Text_License). يُحفظ النص دون تغيير مع الإشارة إلى المصدر وإشعار الاستخدام.
- صفحات المصحف: [quran-ws/quran-svg](https://github.com/quran-ws/quran-svg) — صفحات مصحف المدينة النبوية (حفص) المستندة إلى ملفات مجمع الملك فهد لطباعة المصحف الشريف. راجع `app/src/main/assets/MUSHAF_NOTICE.txt` وإشعار المصدر المضمّن.
- ترخيص الشيفرة: MIT. موارد القرآن تتبع شروط مصادرها المذكورة أعلاه.

## ملاحظات الاختبار
تمت إضافة فحوصات بيانات وتهيئة CI، لكن لا تُعتبر النسخة جاهزة للنشر النهائي إلا بعد نجاح تشغيل GitHub Actions واختبار APK فعليًا على جهاز Android، بما في ذلك اختبار وضع الطيران. ميزة الصوت ما زالت غير متوفرة في هذا الإصدار.
